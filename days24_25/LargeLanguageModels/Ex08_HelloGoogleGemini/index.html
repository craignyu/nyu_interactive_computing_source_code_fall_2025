Hello Google Gemini

To use this example you will need to obtain a Google Gemini API key. Here's how you can do this:

  • Visit https://aistudio.google.com/app/apikey
  • Consent to the Google API Terms of Service and click "I accept"
  • Click the "Create API key" button

Some important notes:

  • Generative AI APIs have usage limits, and thus require API keys.
  • Because of this, we don't want to expose the key here in the JavaScript where anyone can see it by viewing the source of the page.
  • To get around this, this page will prompt you to enter a Google Gemini API key. It will then store the API key in localStorage for later use.
  • A more comprehensive solution would be to set up a back end (server-side) program that acts as a "proxy" to contact Google Gemini on your behalf. This proxy server can then store your API key securely.
